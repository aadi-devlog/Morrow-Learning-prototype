# Morrow Learning | CSS-fixed project

This is a flat, static website package. All three code files are in the same folder so the stylesheet and JavaScript paths are straightforward.

## Files

- `index.html` — website markup
- `styles.css` — all website styling
- `script.js` — navigation, image fallback and enquiry-form interactions
- `preview-project-gallery.png` — project gallery preview
- `preview-landing-page.png` — full-page landing-page preview (local fallback imagery used for the screenshot)
- `preview-mobile.png` — full-page responsive mobile preview
- `research-and-design-rationale.md` — design rationale

## Run locally

1. Extract the ZIP completely.
2. Keep all files together in the extracted folder.
3. Open `index.html` in a modern browser.

Do not move `styles.css` into another folder unless you also update the stylesheet link in `index.html`. The enquiry form is a local prototype and does not transmit or store information.
